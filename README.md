# vex-portfolio

Le portfolio de Vex Labs, le studio de vex et Claude : https://vexlab-off.github.io/vex-portfolio/

Site statique, sans dépendance ni étape de build :

- `index.html`, `confidentialite.html`, `cgu.html` : les trois pages ;
- `css/site.css` : la feuille de style commune ;
- `js/site.js` : le comportement de l'accueil (menu, horloge Meridian et sa construction, projets, duo, copie de l'adresse) ;
- `fonts/`, `media/` : les polices hébergées avec le site et les images.

Pour le voir en local : `python -m http.server` dans ce dossier, puis http://localhost:8000.
